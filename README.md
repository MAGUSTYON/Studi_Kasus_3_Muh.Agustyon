# Studi_Kasus_3_Muh.Agustyon
Sistem Watchlist & Rating Anime
Program Python sederhana untuk mengelola data anime (judul, genre, rating) menggunakan list sebagai tempat penyimpanan sementara. Gaya program mengikuti pola input perintah teks (seperti sistem peminjaman buku), dibuat untuk tugas mata kuliah Dasar Pemrograman.
Deskripsi Program
Program berbentuk menu berulang (while) yang menerima perintah berupa teks:
tambah  -> menambahkan data anime baru
lihat   -> menampilkan seluruh data anime
ubah    -> mengubah rating anime yang sudah tercatat
hapus   -> menghapus data anime
selesai -> keluar dari program & menampilkan ringkasan

Konsep yang Digunakan
Variabel & tipe data (str, int, list, tuple)
Operator (perbandingan, aritmatika, penugasan)
Conditional statement (if - elif - else) untuk validasi perintah dan pengecekan data
Looping (while, for, range) untuk menu berulang dan pencarian data
Operasi list: append(), del, indeks, tuple sebagai isi
